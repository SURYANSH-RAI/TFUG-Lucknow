# <img src="./public/AICL-logo-transparent.svg" alt="TFUG Lucknow Logo" height="40" style="vertical-align: middle; margin-right: 10px;"> AI Community Lucknow Website

This repository contains the official website for TensorFlow User Group (TFUG) Lucknow. The website serves as a hub for the community, showcasing events, community leaders, resources, and ways to connect with the Lucknow TensorFlow and machine learning community.

> **Note:** This site is designed specifically for TFUG Lucknow Chapter. Using it or copying code without organizer's permit and proper mail may result in legal issues.

## 🚀 Features

- **Responsive Design**: Built with mobile-first approach for optimal viewing on all devices
- **Modern UI**: Clean, intuitive interface with a dark theme that aligns with the TensorFlow brand
- **Interactive Components**: Animations and interactive elements for an engaging user experience
- **Community Showcase**: Sections for community leaders, events, and resources
- **Contact Information**: Easy access to social media links and contact details
- **Location Map**: Interactive map showing Lucknow's location

## 🛠️ Tech Stack

- **React 19**: For building the user interface
- **Vite**: As the build tool and development server
- **TailwindCSS**: For styling with utility-first CSS
- **Motion**: For smooth animations and transitions
- **Lucide React**: For modern, customizable icons
- **ESLint**: For code linting and maintaining code quality

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/TFUG-Lucknow.git
   cd TFUG-Lucknow
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## 📦 Build for Production

To create a production build:

```bash
npm run build
# or
yarn build
```

Preview the production build:

```bash
npm run preview
# or
yarn preview
```
